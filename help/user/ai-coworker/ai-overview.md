# Journey Optimizer B2B Edition의 AI 기능

[!DNL Adobe Journey Optimizer B2B Edition]의 AI 기능을 사용하여 콘텐츠를 생성하고 제품 지식을 탐색하며 운영 통찰력을 얻으십시오.

>[!IMPORTANT]
>
>[!DNL Journey Optimizer B2B Edition]에서 AI 기능을 사용하려면 [사용자 지침](https://www.adobe.com/kr/legal/licenses-terms/adobe-gen-ai-user-guidelines.html){target="_blank"}에 동의해야 합니다. 이 계약에는 공개 베타 계약도 포함되어 있어 롤아웃할 때 AI 지원 기능을 추가로 사용할 수 있습니다.

## [!DNL Coworker] 앱 사용 {#coworker-app}

콘텐츠 생성이 아닌 모든 채팅 워크플로에 [!DNL CX Enterprise Coworker] 앱 인터페이스를 사용하십시오. 제품 관련 질문과 운영 통찰력을 살펴보고 B2B 계정 및 사용자에 대한 [여정 기술](../agents/journey-agent.md) 및 [대상 기술](../agents/audience-agent-b2b.md)을 사용하세요. 콘텐츠 생성은 [!DNL Journey Optimizer B2B Edition] 내에서 계속 사용할 수 있습니다.

앱 열기, 대화 시작 및 채팅 기능 사용에 대한 지침은 [CX Coworker 인터페이스 안내서](https://experienceleague.adobe.com/ko/docs/coworker/content/chat/ui-guide){target="_blank"}를 참조하세요.

[!DNL Coworker] 채팅 쿼리를 제출하기 전에 필요한 조회 유형을 고려하십시오.

### 제품 지식

제품 지식은 [!DNL Adobe Experience League]의 [!DNL Journey Optimizer B2B Edition] 설명서에 나와 있는 개념과 주제를 참조합니다. 제품 지식 질문은 다음 하위 그룹에 추가로 지정할 수 있습니다.

| 제품 지식 | 예 |
| --- | --- |
| 뾰족한 학습 | <li>구매 그룹이란 무엇입니까? <li> 구매 그룹 역할 템플릿의 예를 보여 주시겠습니까? |
| 공개 검색 | <li>구매 그룹을 만드는 단계는 무엇입니까? <li>구매 그룹 역할 템플릿에서 사용자 정의 필드를 사용하는 방법은 무엇입니까? |
| 문제 해결 | <li>내 여정에 사용할 그룹을 만들지 않은 이유는 무엇입니까? <li>여정에서 수신할 경험 이벤트를 찾을 수 없는 이유는 무엇입니까? |

### 운영 인사이트

_Operational insights_&#x200B;는 [!DNL Coworker]이(가) 메타데이터 개체(특성, 계정 대상, 데이터 흐름, 데이터 세트, 대상, 계정 여정, 스키마, 원본, 구매 그룹 템플릿 및 솔루션 관심 분야)에 대해 생성하는 답변을 참조합니다. 이러한 통찰력에는 카운트, 조회 및 계보 영향이 포함됩니다. 샌드박스 내의 데이터는 보지 않습니다.

* 대상자 규모가 가장 큰 계정 대상자는 무엇이며 해당 규모는 무엇입니까?
* 여정에서 한 번도 사용한 적이 없는 계정 대상은 몇 명입니까?
* 솔루션 관심사 _x_&#x200B;을(를) 사용하는 활성 여정은 무엇입니까?

### 개인 정보, 보안 및 거버넌스

[!DNL Journey Optimizer B2B Edition]의 [!DNL Coworker] 채팅은 개인 정보, 보안 및 거버넌스의 우선 순위를 갖습니다. [!DNL Coworker] 채팅에서 기대할 수 있는 고객 신뢰 집중 기능에 대해 알아보려면 다음 정보를 검토하십시오.

* [!DNL Coworker]은(는) 교육 목적으로도 현재 개인 데이터를 사용하지 않습니다.

* [!DNL Coworker] 채팅과 함께 이전 상호 작용의 30일 로그를 볼 수 있습니다.

* [!DNL Coworker]은(는) 프롬프트에 응답할 때 샌드박스 특정 데이터 및 공개 Adobe 설명서에 있습니다. 데이터는 샌드박스 간에 공유되지 않습니다.

* [!DNL Coworker] 채팅에 제공한 프롬프트가 다른 고객에게 공유되지 않습니다.
