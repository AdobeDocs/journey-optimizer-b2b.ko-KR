# 콘텐츠 모듈

[!DNL Adobe Journey Optimizer B2B Edition]의 모듈을 사용하여 준비된 레이아웃에서 콘텐츠를 조합합니다. 각 모듈은 [구조](./structure-components.md) 및 [콘텐츠 구성 요소](./content-components.md)를 자신의 텍스트, 이미지 및 링크로 바꾸는 기본 콘텐츠와 결합합니다.

개별 콘텐츠 구성 요소와 달리 모듈은 머리글, 배너, 카드 및 바닥글과 같은 전체 섹션을 제공합니다. 빈 공간에서 각 섹션을 빌드하는 대신 캔버스에 모듈을 추가한 다음 해당 구성 요소를 사용자 지정합니다.

모듈이 [시각적 조각](./fragments.md)과 다릅니다. 모듈은 디자인하는 콘텐츠의 일부가 됩니다. 시각적 조각은 이메일 및 이메일 템플릿 간에 재사용할 수 있는 저장된 콘텐츠 자산입니다.

## 모듈 탭

다음 콘텐츠 형식에 대한 시각적 디자인 공간의 **[!UICONTROL 모듈]** 탭을 사용하십시오.

* 전자 메일 - [_전자 메일 콘텐츠 작성_](./email-authoring.md)&#x200B;을 참조하세요.
* 랜딩 페이지 - [_랜딩 페이지 디자인_](./landing-page-design.md)&#x200B;을 참조하세요.
* 시각적 조각 - [_조각 작성_](./fragment-authoring.md)&#x200B;을 참조하십시오.
* 전자 메일 템플릿 - [_전자 메일 템플릿 작성_](./email-template-authoring.md)&#x200B;을 참조하세요.
* 랜딩 페이지 템플릿 - [_랜딩 페이지 템플릿 디자인_](./landing-page-template-design.md)&#x200B;을 참조하세요.

![시각적 디자인 캔버스 옆에 표시되는 모듈 범주](./assets/modules-left-panel.png){width="600" zoomable="yes"}

## 모듈 카테고리

레이아웃을 선택하려면 범주를 확장합니다. 이러한 레이아웃은 1열, 2열 또는 3열과 같은 단면 컨텐츠의 상이한 배열들을 제공한다.

| 카테고리 | 사용 |
| --- | --- |
| [!UICONTROL 머리글] | 로고, 탐색 링크 및 소개 텍스트로 콘텐츠를 소개합니다. |
| [!UICONTROL 영웅] | 배너 섹션으로 공지 또는 프로모션을 강조 표시합니다. |
| [!UICONTROL 평가] | 스타일이 지정된 섹션에 고객 견적을 제시합니다. |
| [!UICONTROL 카드] | 제품, 문서 또는 기타 콘텐츠 항목을 격자로 정렬합니다. |
| [!UICONTROL 팀] | 사진, 이름 및 역할을 사용하여 팀원, 작성자 또는 발표자를 소개합니다. |
| [!UICONTROL 바닥글] | 탐색 링크, 소셜 링크 및 법적 텍스트로 콘텐츠를 완료합니다. |

## 모듈 추가 및 사용자 지정

만들려는 섹션과 일치하는 모듈로 시작한 다음 콘텐츠 및 스타일을 조정합니다. 기본 링크 및 텍스트를 채널에 적합한 콘텐츠로 바꿉니다.

>[!NOTE]
>
>마케팅 이메일의 경우 여정을 게시하기 전에 옵트아웃 링크와 [이메일 경고를 확인](./add-email.md#check-alerts)하세요.

1. 시각적 디자인 공간에서 이메일, 랜딩 페이지, 시각적 조각 또는 템플릿을 엽니다.

   기본적으로 **[!UICONTROL 모듈]** 탭이 표시됩니다.

1. 사용 가능한 레이아웃을 검토하려면 카테고리를 확장합니다.

   검색 필드를 사용하여 이름으로 모듈을 찾을 수도 있습니다.

1. 모듈을 캔버스로 드래그합니다.

   ![모듈 목록이 검색으로 필터링되고 모듈이 캔버스로 드래그됩니다.](./assets/modules-search-drag.png){width="600" zoomable="yes"}

1. 모듈 내의 요소를 검토합니다.

   각 모듈에는 편집할 수 있는 기본 콘텐츠가 포함되어 있습니다. 캔버스 왼쪽에 있는 _탐색 트리_ 아이콘(![탐색 트리 아이콘](../assets/do-not-localize/icon-navigation-tree.svg))을 클릭하여 모듈의 구조 및 요소를 표시합니다.

   ![탐색 트리에 선택한 모듈의 구조와 요소가 표시됩니다.](./assets/modules-navigation-tree.png){width="600" zoomable="yes"}

1. 모듈에서 요소를 선택하여 사용자 지정합니다.

   기본 텍스트를 바꾸고 에셋에서 이미지를 선택하고 콘텐츠의 링크를 업데이트할 수 있습니다.

   **[!UICONTROL 설정]** 및 **[!UICONTROL 스타일]** 탭을 사용하여 선택한 구성 요소를 조정합니다.

   ![스타일 옵션이 표시된 모듈에서 선택한 텍스트 구성 요소](./assets/modules-select-element-styles.png){width="600" zoomable="yes"}

1. 다른 요소를 추가하려면 **[!UICONTROL 구성 요소]** 탭을 선택하고 [콘텐츠 구성 요소](./content-components.md)를 모듈로 드래그합니다.

   구성 요소를 모듈 구조에 추가하면 기본적으로 모듈 스타일이 상속됩니다. 필요에 따라 스타일을 조정합니다.

   ![텍스트 구성 요소를 서식 있는 자리 표시자 텍스트가 표시된 모듈 구조로 끌어서 놓았습니다](./assets/modules-select-element-add-component.png){width="800" zoomable="yes"}

1. 변경 내용을 저장하려면 **[!UICONTROL 저장]**&#x200B;을 선택하세요.

>[!NOTE]
>
>브랜드 테마가 이메일 콘텐츠에 적용되면 모듈은 해당 스타일을 상속합니다. 테마를 설정하고 스타일을 재정의하려면 [전자 메일 콘텐츠 작성에 테마 사용](./brand-themes.md#use-email-theme)을 참조하세요.

## 사용자 지정된 모듈 컨텐츠 재사용

전자 메일 또는 전자 메일 템플릿에서 사용자 지정된 모듈을 다시 사용하려면 [콘텐츠를 시각적 조각으로 저장](./fragments.md#save-a-new-fragment-from-email-or-template-content)하십시오. 그런 다음 다른 이메일 또는 이메일 템플릿에 조각을 삽입합니다.

시각적 조각을 작성하는 동안 추가된 모듈의 경우 저장하고 [조각을 게시](./fragments.md#create-fragments)하십시오. 이렇게 하면 재사용이 가능합니다.
